# Tests and Config

This page documents the non-runtime files in the SDK repo: tests, package manifests, TypeScript config, Turbo config, workspace config, and lockfile.

## Root Package

Source file: `package.json`.

The root package is private and named `vantage-plugin-sdk-root`.

Scripts:

- `build`: `turbo build`
- `dev`: `turbo dev`
- `lint`: `turbo lint`
- `test`: `turbo test`

Dev dependencies:

- `turbo`
- `typescript`

Engines require Node `>=20.0.0` and pnpm `>=9.0.0`.

The package manager is pinned to `pnpm@10.33.2`.

## Workspace

Source file: `pnpm-workspace.yaml`.

The workspace includes every package under:

```yaml
packages:
  - 'packages/*'
```

## Backend Tests

Source file: `packages/plugin-sdk/src/__tests__/backend.test.ts`.

Test helpers:

- `makeBridge(data)` returns a Vitest mock bridge that resolves with `{ data, error: null }`.
- `makeErrorBridge(code, message)` returns a mock bridge that resolves with `{ data: null, error }`.

Covered behavior:

- `list` calls `{resource}.list` with `{ filter }`.
- `get` calls `{resource}.get` with `{ id }`.
- `create` calls `{resource}.create` with `{ data }`.
- `update` calls `{resource}.update` with `{ id, data }`.
- `delete` calls `{resource}.delete` with `{ id }`.
- bridge errors are thrown by normal methods.
- `safe.get` returns `{ data: null, error }` instead of throwing.
- `safe.list` returns `{ data, error: null }` on success.
- `storage.get` and `storage.set` dispatch expected bridge calls.
- `on` plus `_dispatchHook` invokes registered hook handlers.
- multiple handlers for one event all run.
- handlers for unrelated events do not run.
- `table(name).list(...)` dispatches `table.list` with the table name.

## Frontend Tests

Source file: `packages/plugin-sdk/src/__tests__/react.test.tsx`.

Test helpers:

- `makeBridge(data)` returns a successful mock bridge.
- `makeRegistry()` creates empty `pages`, `widgets`, and `panels` maps.

Covered behavior:

- `createFrontendPlugin` returns the config object unchanged.
- returned `setup` is callable with a `VantageFrontendImpl`.
- `registerPage` stores a component in the registry.
- `registerWidget` stores a component in the registry.
- `registerPanel` stores panel data under a composite key.
- `settings.get` returns `null` on bridge error.
- `list` calls `{resource}.list`.
- `get` calls `{resource}.get`.
- `bus.on` registers a handler and its unsubscribe removes it.
- frontend `table(name).list(...)` dispatches `table.list` with the table name.

## Lockfile

Source file: `pnpm-lock.yaml`.

The lockfile pins the resolved dependency graph for the workspace. It is generated by pnpm and should not be hand-edited. It covers root dev dependencies, workspace package links, SDK test dependencies, React dependencies, TypeScript, Turbo, jsdom, and transitive packages.

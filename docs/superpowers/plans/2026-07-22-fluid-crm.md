# Fluid CRM Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Rebuild the CRM module (contacts, companies, pipeline, tasks, activity, contact detail) in the Vencore Fluid design language, extending schema/API where the new design needs data the model lacks, reusing all existing data/auth wiring.

**Architecture:** Consumes the Fluid Foundation (spec 1): `(fluid)` shell, primitives, registries, hosts. CRM routes migrate from `app/(dashboard)/crm/*` to `app/(fluid)/crm/*` (URLs unchanged). New DB columns come from new Kysely migrations (never editing existing ones), threaded `schema.ts` → `@vencore/types` → Zod → route handlers, each backend change TDD-first. A new `GET /api/contacts/:id/overview` aggregate powers the detail page in one call. Frontend screens are new components under `modules/crm/fluid/` reusing existing data libs + Foundation primitives.

**Tech Stack:** Next.js App Router (TS), React, Kysely + PostgreSQL, Express + Zod, vitest (api: `vitest run` + hand-rolled Kysely mock chain; web: `.test.ts` pure logic), react-query/RTK.

## Global Constraints

- TypeScript strict, **no `any`**, no `console.log` in prod (use `logger`).
- **Never edit existing migrations.** New files `packages/db/migrations/YYYYMMDD_NNN_<name>.ts` with `up`/`down`.
- Every route: Zod-validate, `{ data, error }` envelope, workspace-scoped (`req.workspace.id` via `AuthenticatedRequest`), soft-delete aware (`deleted_at is null`).
- Do **not** change the `contacts.status` enum — Active/Lead/Dormant are **derived views**.
- New columns nullable/defaulted — back-compatible.
- **Deal priority derived** from `probability`: `urgent≥80, high≥60, medium≥30, else low` (no migration).
- **Company detail deferred** (redesign HTML has list only).
- Reuse Foundation primitives from `@/modules/shared/fluid/ui`.
- Git: branch `claude/refactor-crm-redesign-94d91e`; sole author Kavin-Charles, no AI attribution; one small commit per task. **Foundation plan merged first.**

```ts
// apps/api/src/routes/contacts-overview.ts
import { Router, type Router as ExpressRouter } from 'express';
import type { Kysely } from 'kysely';
import type { Database } from '@vencore/db';
import type { AuthenticatedRequest } from '../middleware/auth';

export function createContactsOverviewRouter(db: Kysely<Database>): ExpressRouter {
  const router = Router();
  router.get('/:id/overview', async (req, res, next) => {
    try {
      const { workspace } = req as unknown as AuthenticatedRequest;
      const id = req.params['id']!;
      const contact = await db.selectFrom('contacts').selectAll()
        .where('workspace_id', '=', workspace.id).where('id', '=', id)
        .where('deleted_at', 'is', null).executeTakeFirst();
      if (!contact) { res.status(404).json({ data: null, error: { code: 'NOT_FOUND', message: 'Contact not found.' } }); return; }
      const deals = await db.selectFrom('deals').selectAll()
        .where('workspace_id', '=', workspace.id).where('contact_id', '=', id)
        .where('deleted_at', 'is', null).execute();
      const activities = await db.selectFrom('activity').selectAll()
        .where('workspace_id', '=', workspace.id).where('contact_id', '=', id)
        .orderBy('created_at', 'desc').limit(50).execute();
      const totalDealValue = deals.reduce((s, d) => s + Number(d.value ?? 0), 0);
      const funnel = new Map<string, number>();
      for (const d of deals) { const k = d.stage_id ?? 'unstaged'; funnel.set(k, (funnel.get(k) ?? 0) + Number(d.value ?? 0)); }
      res.json({ data: {
        contact, deals, activities,
        metrics: {
          total_deal_value: totalDealValue, interaction_count: activities.length,
          current_stage: deals[0]?.stage_id ?? null,
          last_contact_at: contact.last_contacted_at ? new Date(contact.last_contacted_at).toISOString() : null,
        },
        stage_funnel: [...funnel.entries()].map(([stage, total]) => ({ stage, total })),
      }, error: null });
    } catch (e) { next(e); }
  });
  return router;
}
```

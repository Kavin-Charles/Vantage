# Code of Conduct

## The short version

Be respectful. Criticism of code and ideas is welcome. Criticism of people is not.

## The longer version

This project is open to contributors regardless of experience level, background, or identity. We expect everyone participating — in issues, PRs, discussions, or anywhere else — to treat others with basic respect.

**This means:**
- Disagreeing with someone's approach is fine. Attacking them personally is not.
- Asking beginner questions is encouraged.
- If someone makes a mistake, point it out clearly and move on.

**This does not mean:**
- All contributions get merged. Technical disagreements will happen and maintainers have final say.
- You can't have strong opinions. Strong technical opinions expressed respectfully are a feature, not a problem.

## Enforcement

Behavior that violates this code of conduct will result in a warning, and repeated violations will result in being blocked from the project. There's no elaborate process — use common sense.

To report an issue, open a GitHub issue marked `[conduct]` or contact the maintainers directly.
